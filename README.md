# AI FM (aifm.ro)

Radio non-stop, condus de un AI care nu doarme. Gazda: **Vio**.

## v1 (current)
Mobile-first landing page on Next.js 14 + Tailwind. Visual prototype only — no real stream yet.

## Stack
- Next.js 14 (App Router)
- Tailwind CSS
- TypeScript
- Deployed on Vercel

## Local dev
```bash
npm install
npm run dev
```

## Roadmap
